# Deterministic Windows x64 package implemented

Replaced the timestamped host archive with the contract name
`nxp-cup-core-tools-win-x64-<version>.zip`. The flat archive contains the two
native executables, SDL2, pinned rblhost, all required notices, a runtime
README, and `manifest.json`. The manifest records the source commit, target,
source-tree dirty state, tool versions, pinned rblhost provenance, payload
sizes, and lowercase SHA-256 digests. A sibling
`.zip.sha256` file protects the complete archive.

The ZIP writer sorts entries and assigns fixed metadata rather than inheriting
filesystem timestamps. Two consecutive packages of unchanged runtime inputs
produced the identical SHA-256
`a2c7168b6cce8787596285e33eacbb481b624544be26fcb30a954de1112b0bf7`.
The packager refuses to replace an existing version unless `-Force` is
explicit, and verifies the bundled rblhost remains version 0.2.0.
The bundled rblhost binary must also match the SHA-256 recorded in its vendor
record.

The post-review full release dry run produced a 3,168,407-byte test archive
with SHA-256
`6fb853082274228c14d41dd67313bb4910afbb5fd14675f78db6476a7eeda028`.
No GitHub asset was uploaded.
