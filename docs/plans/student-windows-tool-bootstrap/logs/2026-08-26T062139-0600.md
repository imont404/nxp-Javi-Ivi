# Base Windows provisioning hardened

Added `setup.versions.json` as the single checked-in setup pin definition. Arm
GNU 14.2.Rel1 now records the official 305,393,359-byte archive URL and SHA-256,
the expected GCC 14.2.1 version, and the extracted compiler SHA-256. Setup retains
the verified archive under `out/downloads`, extracts into a bounded staging path,
verifies the candidate compiler, and only then switches it into
`out/toolchains` with rollback.

Replaced the silent BITS interval with a streaming downloader that emits visible
ten-percent byte milestones. CMake and Ninja now must be executable and pass
their version commands after installation. Setup refreshes only its process PATH
after winget changes and fails instead of printing completion when either required
tool remains unavailable. uv and LLVM-MinGW moved behind the explicit
`-IncludeMaintainerTools` switch.

Ran the ordinary unskipped setup from this worktree with no local Arm installation.
The official archive downloaded with progress, matched SHA-256
`6facb152ce431ba9a4517e939ea46f057380f8f1e56b62e8712b3f3b87d994e1`,
extracted successfully, and installed GCC 14.2.1. A clean competition build then
compiled all 89 C commands with the repository-local compiler and published the
normal AXF and BIN.
