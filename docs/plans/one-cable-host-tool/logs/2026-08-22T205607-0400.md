# Log: native-preview

Implemented the first native Windows SDL2/Dear ImGui viewer over the shared host core. It auto-selects only one exact VID_1FC9/PID_0094 runtime device, performs HELLO and a framed frames/stats/logs/telemetry subscription, renders RGB565, reports connection and telemetry state, reconnects after disconnect, and supports a bounded hidden smoke test. Release build passed /W4 /WX for project sources. Live --test-seconds 5 received 113 complete frames with zero malformed packets (about 22.6 FPS); a fresh CLI full-frame probe immediately afterward also passed, proving clean session/device release. Initial proof reuses repository SDL2 and pinned ImGui v1.91.9b; offline vendoring remains the later dependency-hardening step. The formal step remains pending until its device-discovery dependency is closed by the physical ROM HID proof.
