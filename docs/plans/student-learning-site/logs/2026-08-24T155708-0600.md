# Log: RGB565 and YHSV lookup lesson

Added the second generated standalone lesson, `docs/learn/rgb565-lookup.html`.
It follows the firmware's exhaustive 65,536-entry RGB565 lookup contract and
visualizes the entire 16-bit address space as an interactive 256 by 256 color
map. A selected word exposes its R5/G6/B5 fields and packed `0xVVSSHHYY`
result. The lesson contrasts the per-pixel masks, expansion, luma arithmetic,
max/min work, hue-sector branching, division, and byte quantization with the
runtime indexed 32-bit load, while stating the 256 KiB flash tradeoff and the
remaining student-owned classification decisions.

The Y output has its own live weighted-contribution graphic for the exact
integer BT.601 expression. It explains the different red, green, and blue
weights, rounding and division-by-256 steps, and the distinction between this
encoded-RGB luma byte and physical calibrated luminance.

The runtime comparison now shows the actual public `color_features_t` API, so
students access the four results as `.y`, `.h`, `.s`, and `.v` byte fields
without writing shifts. An expandable framework view shows the internal packed
word unpacking. A visible build-time code panel records the RGB565 bit
expansion, luma expression, normalized HSV equations and hue sectors, byte
quantization, and final `0xVVSSHHYY` packing that each lookup replaces.

Generalized `build_learning_pages.py` to package multiple pages and to omit the
Three.js payload from lessons that do not use it. Direct-file Playwright tests
cover desktop interaction, exact primary-red table values, phone layout, and
the no-network contract. Python coverage checks both standalone artifacts and
the authoritative LUT generator.
