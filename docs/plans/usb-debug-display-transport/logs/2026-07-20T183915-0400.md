# Log: host-receiver-proof

AVC CMake firmware was flashed with the integrated HS USB CDC debug stream enabled. The device enumerated on Windows as `USB Serial Device (COM15)` with the NXP sample VID/PID `1FC9:0094`.

Initial AVC synthetic-gradient streaming worked functionally but was slow because the main loop only queued one chunk per service pass: `0.327 MiB/s`, `2.70 fps`, zero parser errors over 10 seconds.

Moved chunk scheduling to the CDC send-complete callback and changed the proof payload to a prefilled static RGB565 buffer so the test measures prepared-buffer transport, which matches the future camera-frame path better than per-byte gradient generation. Rebuilt and flashed successfully with `./build_cmake.ps1` and `./flash.ps1 -CMake`.

Throughput results against the AVC firmware on COM15:

- Python receiver, `uvx --from pyserial python .../usb_cdc_stream_read.py --port COM15 --seconds 10 --read-size 1048576 --rx-buffer-size 16777216`: `34.135 MiB/s`, `279.06 fps` equivalent for `320x200 RGB565`, `0` malformed headers, `0` sequence errors after initial sync.
- Native Win32 receiver, `tools/bin/usb_cdc_stream_read.exe --port COM15 --seconds 10 --read-size 1048576 --rx-buffer-size 16777216`: `34.422 MiB/s`, `281.45 fps` equivalent, `0` malformed headers, `0` sequence errors after initial sync.

Added a native C++ host receiver plus `tools/build_usb_cdc_stream_read.ps1`. The build wrapper uses Visual Studio 2022 Build Tools discovered through `vswhere` and `vcvars64.bat`; no LLVM install was needed on this machine. Added `tools/README.md` documenting Python/native receiver usage and build-tool setup, and ignored generated native outputs under `tools/bin`.

Current interpretation: CDC ACM/VCOM is good enough for this stage and is not the immediate limiter. The class API still exposes only one in-flight bulk-IN request per endpoint, so a later thin endpoint layer over `USB_DeviceSendRequest()` remains an option if camera-frame streaming needs lower overhead, double buffering, or tighter endpoint ownership.
