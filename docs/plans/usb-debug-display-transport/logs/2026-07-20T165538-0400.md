# Log: sample-intake

Studied the local FRDM-MCXN947 USB examples and active AVC frame path.

Findings: the CDC VCOM and UVC virtual camera examples both use the HS EHCI device controller. The EHCI path is interrupt-driven at the software boundary but uses queue heads and dTDs for controller DMA of payload buffers. The CDC sample has HS 512-byte bulk endpoints, attachment/open gating through attach and startTransactions, and is the right first transport proof. The UVC sample is useful for compatibility research, but its local implementation is MJPEG 176x144 with a 512-byte isochronous payload buffer and is not the best first raw RGB565 debug-display path.

Decision: start with an isolated USB-only synthetic frame streamer before integrating camera or AVC frame ownership. This isolates HS enumeration, host/browser/app receive behavior, sustained throughput, endpoint busy behavior, and no-host idle behavior.
