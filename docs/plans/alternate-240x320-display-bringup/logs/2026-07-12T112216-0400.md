Flashed the CM33 ER-TFT020-7 8080 bit-bang test image so the raw signals can
be scoped before wiring the display.

Flash details:

- Image:
  `build/cmake/avc_core0-Debug-parallel-bitbang/avc_core0.axf`.
- The default `flash.ps1` J-Link path pointed at V9.40, which is not installed
  on this machine.
- The installed J-Link path is
  `C:\Program Files\SEGGER\JLink_V954\JLink.exe`.
- Flash succeeded with J-Link Commander V9.54.
- J-Link reported `VTref=3.300V`, programmed and verified the image, then
  reset and started the target.

Schematic finding:

- The BuyDisplay `ER-TFT020-7_Interfacing.pdf` 8080 Series I reference ties
  `IM2=GND`, `IM1=GND`, and `IM0=GND`.
- The SPI strap states are different, so the display must be restrapped before
  the 8080 bus proof.

Script cleanup:

- Updated `flash.ps1` and `rtt.ps1` to auto-detect the newest installed
  `C:\Program Files\SEGGER\JLink_V*` tool path if their configured path is
  missing.
