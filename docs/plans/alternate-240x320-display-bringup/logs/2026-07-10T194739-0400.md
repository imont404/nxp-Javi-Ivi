# Log: Initial ER-TFT020-7 Plan And Research

Started the alternate 240x320 display bringup plan for the BuyDisplay
ER-TFT020-7 panel.

Research captured:

- Product page: ER-TFT020-7, 2 inch IPS TFT, 240x320, ST7789 controller.
- Module datasheet summary: interface listed as `3/4-wire SPI, 6800 8-bit
  Parallel`; product title says `MCU 8080 Parallel Interface`, so the parallel
  bus style is an open item.
- Important FPC naming issue: in 4-wire SPI mode, ER-TFT020-7 FPC pin 17
  (`RS`) is the serial clock and FPC pin 16 (`WR`) is the data/command select.
- FPC pin 19 is `TE`, which is worth evaluating after SPI display operation is
  stable.
- Current AVC firmware already has an ST7789/LPSPI path using LPSPI1,
  `PIO0_26` as display D/C, and `PIO0_28` as display reset.

Collateral status:

- Created `docs/research/ER-TFT020-7`.
- Created `source_manifest.md` with the BuyDisplay product, datasheet,
  controller, connector, touch, demo-code, and dev-board URLs.
- Automated shell downloads from BuyDisplay were blocked by HTTP 403 /
  Cloudflare challenge responses.
- Copied the existing local ST7789 datasheet from `docs/lcd/ST7789vw.pdf` to
  `docs/research/ER-TFT020-7/downloads/ST7789vw_existing_local_copy.pdf` as a
  temporary local controller reference.

Initial strategy:

- First prove the ER-TFT020-7 in 4-wire SPI mode using the existing AVC LCD
  pins and current ST7789 driver.
- Add a guarded synthetic RGB565 display test before routing live camera frames.
- Do not start EZH/bunny parallel work until the demo ZIP/schematic material
  resolves the 6800-vs-8080 wording and the actual IM strap requirements.
- Treat TE as a second-stage GPIO-timestamp measurement using the same OSTIMER
  style already used for camera timing.
