# Log: Captured ER-TFT020-7 RS Signal Mode Change

Recorded the ER-TFT020-7 FPC pin 17 role change in the active plan.

Important signal note:

- FPC pin 17 is `RS`.
- In SPI mode this physical pin is used as the serial clock.
- In parallel mode it is the display data/command select.
- The parallel/EZH pin map must not treat FPC pin 17 as an SPI-only signal.
- The first bounded EZH command proof should either have EZH drive RS directly
  with `WR`, `CS`, and D0..D7, or keep RS as an ARM GPIO only if command and
  data bursts are separated with explicit ownership.
