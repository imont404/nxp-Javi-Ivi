# Log: freeze-student-surface

Implemented the generic RGB565-to-YHSV conversion foundation on 2026-08-21 without freezing the wider student API. scripts/tools/generate_rgb565_color_lut.py deterministically generates and exhaustively validates the committed 65,536-entry packed uint32 table (Y,H,S,V bytes). The existing test-mode scanline now uses one indexed 32-bit lookup per pixel; float HSL conversion and unused float HSL gradient/adaptive/hybrid experiments were removed. The table contains no track/color classes. Competition and flexio-port1 presets build; the map places the exact 0x40000-byte table in .rodata and the table consumes no SRAM. A clean staged LUT-only competition snapshot uses 354,180 bytes of flash; the current integrated state-machine/telemetry working tree uses 383,368 bytes. The integrated competition image was flashed to Rev A through J-Link and RTT reported SMARTDMA_EZH, System mode TEST, and Camera first frame received. The device USB port was not attached to the PC, so host frame reception was not repeated. Remaining API decision: whether the simple binary edge/segment helpers belong in the student handoff.
