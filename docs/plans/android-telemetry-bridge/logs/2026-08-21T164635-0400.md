# Log: wifi-relay-proof

Implemented the embedded one-client HTTP/WebSocket relay on the Moto G Power 5G (2023). The phone preserves AVCU framing, relays every fourth complete frame through a separate fixed three-buffer latest-frame mailbox, forwards generic telemetry, and exposes /health. Added verify_android_relay.ps1 and integrated it into android_loop.ps1 for unattended complete-frame validation. JVM tests, Android lint, APK build/install, HTTP health, WebSocket reassembly, and browser rendering passed.
