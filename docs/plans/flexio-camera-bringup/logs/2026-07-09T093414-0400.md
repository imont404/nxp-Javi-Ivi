# Log: signal-instrumentation

Hardware handoff for first FlexIO camera signal wiring. The validated firmware
image on the board is still the default SmartDMA/EZH backend from commit
`1e61e07`, so the existing camera path remains the baseline while power is
removed.

Initial wiring target:

- Camera PCLK to `P4_20`.
- Camera HSYNC/HREF to `P4_21`.
- Camera VSYNC to `P4_22`.

Keep existing SCCB/I2C, XCLK, reset, and power-down wiring unchanged. After
power-up, switch to the dormant `FLEXIO_DIAG` backend, flash, and use RTT to
confirm pin levels and then signal counts.
