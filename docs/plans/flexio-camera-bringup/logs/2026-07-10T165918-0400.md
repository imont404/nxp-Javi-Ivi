# Log: flexio-frame-buffer

Visual confirmation of the pulled-low FlexIO/eDMA frame-buffer test.

Observation:

The LCD shows a black camera image with the current `FLEXIO_EDMA` backend.

Interpretation:

This matches the expected result for the current hardware state: camera data
lines disconnected and Port 4 data inputs held low by pulldown/termination.
RTT already showed full-frame DMA completions at 30 frames/sec with
`sample_nz=0` and `first=0000,0000,0000,0000`; the black LCD image confirms
that the DMA-filled frame buffer is also reaching the display path as an
all-zero RGB565 image.

Remaining unknowns:

- Data-bit order.
- RGB565 byte ordering.
- Real OV5640 data signal integrity on `P4_12..P4_19`.
- Whether the overlay/line-processing path needs a raw-frame diagnostic before
  the next data wiring test.
