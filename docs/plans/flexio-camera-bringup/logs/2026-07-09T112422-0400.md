# Log: signal-instrumentation

Hardware handoff for VSYNC cleanup. The first `FLEXIO_DIAG` run showed stable
HSYNC/HREF activity on `P4_21` and PCLK edge activity on `P4_20`, but direct
VSYNC interrupts on `P4_22` produced implausibly high edge counts. Power is
being removed so termination or pulldown matching the other camera signal lines
can be added to the `P4_22` VSYNC jumper.

After power-up, rerun the existing `FLEXIO_DIAG` RTT test. If the polled VSYNC
edge flag remains present and the signal is electrically cleaner, the next
firmware step is to re-enable `P4_22` as an interrupt source and check whether
frame-rate counts become plausible.
