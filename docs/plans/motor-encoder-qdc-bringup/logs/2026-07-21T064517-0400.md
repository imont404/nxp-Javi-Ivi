# Log: qdc-routing-research

Researched Rev A motor connector encoder routing and MCXN947 QDC input paths. J11 maps cleanly through P1_22/TRIG_IN3 and P2_0/TRIG_IN5; J17 maps through P1_0/TRIG_IN0 and P1_1/TRIG_IN1. QDC does not accept arbitrary GPIO directly, so encoder mode must pinmux ALT1 TRIG_IN and route those triggers through INPUTMUX. P2_0/P1_22 conflict with alternate parallel LCD/EZH pin usage and need explicit build-profile ownership before bench validation.
