# Log: encoder-signal-diag

Implemented a gated QDC motor encoder diagnostic build. Normal firmware still defaults to EZH camera, SPI LCD, USB debug stream off, and encoder backend disabled. Diagnostic build owns P1_0/P1_1/P1_22/P2_0 as TRIG_IN inputs, routes them through INPUTMUX to QDC0/QDC1 phase A/B, reports raw IMR, position, delta, counts/sec, direction, and flags over DEBUG, and can optionally toggle low-speed motors from the center button with a 20 percent compile-time PWM cap. Built normal CMake image and motor-enabled diagnostic AXF; not flashed yet.
