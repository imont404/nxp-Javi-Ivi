01 · SAME COLOR

A transform, not a recoloring

Changing from RGB to HSV does not alter the pixel. It changes the questions that are easy to ask. The point on the left and the point on the right always describe the same color.

02 · 24-BIT RGB

Three 8-bit coordinates

A conventional RGB pixel uses one byte for each channel. R, G, and B each range from 0 to 255, giving 24 bits—and more than 16 million possible coordinate combinations.

03 · HSV GEOMETRY

Hue is an angle

Hue is periodic: −10° and 350° point in the same direction. The slider spans −360°…360° so a red filter can be expressed naturally as ±10°. Saturation measures distance from gray; value selects the height and maximum radius.
