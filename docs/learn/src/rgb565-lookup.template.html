65,536 colors

RGB565 spends five bits on red, six on green, and five on blue. Green receives the extra bit because human vision is especially sensitive there.

OUTPUT Y

A weighted brightness estimate

BT.601 luma

Equal RGB numbers do not contribute equally to perceived brightness. Green carries the largest weight, red is next, and blue contributes the least.

Strictly, Y is luma—not physical luminance. It is calculated directly from the encoded RGB bytes. For our vision filters, it is a fast brightness-like score from 0 to 255, not a calibrated measurement of light.

STEP 02

Move the work out of the frame loop

precompute once

Without the table, every pixel must work through this question queue. The generator answers all of it ahead of time for every possible 16-bit word.

CALCULATE DURING EVERY FRAME

  1. Which bits are R, G, and B?mask · shift · expand
  2. How bright does it look?3 multiplies · 2 adds · shift
  3. Which channel is largest and smallest?max · min · delta
  4. Which hue sector owns the pixel?branches around R / G / B
  5. How far is it from gray?divide delta by maximum
  6. How do four results fit in bytes?scale · round · pack

LOOK UP DURING EVERY FRAME

The framework returns a struct, so student code needs no masks or shifts. It sees four ordinary byte fields.

ACTUAL BUILD-TIME WORK

What one table row precomputes

Runs on the PC—not inside the camera frame loop.

# 1. Expand the stored 5/6/5 fields
r5 = (pixel >> 11) & 0x1F
g6 = (pixel >>  5) & 0x3F
b5 =  pixel        & 0x1F

r = (r5 << 3) | (r5 >> 2)
g = (g6 << 2) | (g6 >> 4)
b = (b5 << 3) | (b5 >> 2)

# 2. Integer BT.601 luma
y8 = (77*r + 150*g + 29*b + 128) >> 8
# 3. Traditional HSV equations
rn, gn, bn = r/255, g/255, b/255
maximum = max(rn, gn, bn)
minimum = min(rn, gn, bn)
delta   = maximum - minimum

v = maximum
s = 0 if maximum == 0 else delta / maximum
h = hue_sector(rn, gn, bn, maximum, delta) / 360

# 4. Quantize and pack four bytes
h8 = floor(h * 256) & 0xFF
s8 = floor(s * 255 + 0.5)
v8 = floor(v * 255 + 0.5)
packed = y8 | h8<<8 | s8<<16 | v8<<24
max = RH = 60 × (((G−B)/Δ) mod 6) max = GH = 60 × ((B−R)/Δ + 2) max = BH = 60 × ((R−G)/Δ + 4)

STEP 03

The table supplies measurements—not race decisions

student logic stays visible

Y

Is it dark?

Compare luma with a threshold for black tape or shadow.

H

Is the hue nearby?

Use circular distance—for red, a window can cross 255 → 0.

S

Can hue be trusted?

Low saturation means the pixel is close to gray.

V

Is there enough signal?

Low value means the pixel is close to black.
